# Focus Timer

A Pomodoro timer with a task stack. Finishing a focus session checks off your top task and adds to your streak.

**Try it:** https://masonhagelberg13-spec.github.io/focus-timer/

- 25 / 5 / 15 minute focus, short break, and long break (a long break comes every 4th session)
- The top task shows in the timer and is checked off automatically when a session ends
- Tracks sessions today, your day streak, and focus minutes
- Saved in your browser; no install and no dependencies

Press **Space** to start or pause.
